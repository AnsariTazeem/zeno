# Positive-control equivalence check, not further design search

The unchanged Rg=5000 network passes all six baseline conditions. Numerical
confirmation uses that same captured researcher input. As a grader check,
also evaluate an electrically equivalent network: reverse the unordered Rf/Cf
terminal listing and replace the 5000 ohm reference shunt with two 2500 ohm
series resistors through one private node. No new physical optimization value
or capability claim is introduced. The two networks should receive the same
verdict; if they do not, investigate the apparatus rather than treating the
equivalent circuit as an invalid model solution.

This is equivalent-solution acceptance validation. It is not a second
independently designed passing topology, another task, human performance or
another model trial. The reference's added resistor has an unqualified noise
cost. These positive checks complete the bounded reference qualification;
they do not authorize further reference optimization or model collection.
